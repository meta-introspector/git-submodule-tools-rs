## `boot-tmux.sh`

**Summary:**
This script starts a new detached tmux session named `gemini-agent-session`. It then sends a `gemini` command to this session, which instructs the Gemini agent to read the `boot.md` file. Finally, the script attaches the user to this newly created tmux session. This script is used to initiate and connect to the Gemini agent's operational environment within tmux.
