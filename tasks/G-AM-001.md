# Task ID: G-AM-001

*   **Category:** Agent Management & Automation
*   **Objective:** Develop a Rust-based agent task runner.
*   **Description:** Create a Rust program that can automatically find, claim, and potentially execute tasks based on predefined criteria, serving as a more sophisticated version of `boot.sh`. The program will scan the `tasks/` directory for unclaimed tasks (`Assigned Agent: (Unassigned)`, `Status: To Do`), update the task file to claim it, and provide a framework for triggering task execution (e.g., by calling other Rust binaries or scripts).
*   **Scope:** New Rust crate (`crates/agent_task_runner`), integration with `tasks/` directory.
*   **Acceptance Criteria:**
    *   The `agent_task_runner` binary compiles and runs successfully.
    *   It correctly identifies and claims an unclaimed task by updating the `Assigned Agent` and `Status` fields in the task file.
    *   It provides clear output indicating the claimed task.
    *   Unit tests cover task discovery and claiming logic.
*   **Dependencies:** `gix` (for Git operations), `walkdir` (for scanning `tasks/`).
*   **Assigned Agent:** (Unassigned)
*   **Status:** To Do
*   **Notes:** Consider how to handle concurrent claims by multiple agents (e.g., Git conflicts).
