# Task ID: G-AM-002

*   **Category:** Agent Management & Automation
*   **Objective:** Implement a task completion verification system.
*   **Description:** Develop a Rust program or script that can check if a task's acceptance criteria have been met before marking it as "Done." This could involve running tests, checking file existence, analyzing code changes, or parsing output logs.
*   **Scope:** New Rust crate (`crates/task_verifier`) or a shell script, integration with task definitions.
*   **Acceptance Criteria:**
    *   The `task_verifier` can be invoked for a specific task ID.
    *   It correctly assesses whether the task's acceptance criteria are met.
    *   It provides a clear pass/fail result.
    *   It can update the task's `Status` to `Done` if criteria are met.
*   **Dependencies:** Access to project files, test frameworks, and potentially Git history.
*   **Assigned Agent:** (Unassigned)
*   **Status:** To Do
*   **Notes:** This task will require careful definition of how acceptance criteria are programmatically verifiable.
